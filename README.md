# Bardheim

Bardheim is a Valheim mod that adds craftable playable instruments: a lyre,
hand drum, and flute. Equip an instrument, toggle play mode, use `1-8` for
manual performance, or play local Standard MIDI files from your plugin folder.

Version `0.7.0` is the first public Bardheim release from this standalone repo.
It focuses on local single-player use. Experimental multiplayer audio exists,
but it is disabled by default until a later two-client validation release.

## Features

- Craftable lyre, drum, and flute items registered through Jotunn.
- Manual `1-8` play mode for melodic notes and drum hits.
- Local Standard MIDI format 0/1 playback from user-supplied `.mid` files.
- In-game song selection, speed control, looping, progress, and overlay.
- Lyre tunings, drum General MIDI percussion mapping, and flute melodic folding.
- Embedded lyre, drum, and flute sample banks with generated visual probes and
  inventory icons.
- `Ctrl + F3` support so the Valheim HUD toggle also hides Bardheim's overlay.

## Requirements

- Valheim
- BepInExPack Valheim
- Jotunn

Thunderstore-compatible mod managers should install BepInExPack Valheim and
Jotunn automatically from `package/thunderstore/manifest.json`.

## Installation

The recommended install path is a Thunderstore-compatible mod manager such as
r2modman or Thunderstore Mod Manager.

For manual installs, install BepInExPack Valheim and Jotunn first, then place
the Bardheim DLL here:

```text
BepInEx/plugins/Bardheim/Bardheim.dll
```

Launch the game once after installing. Bardheim creates its song folder when the
plugin loads.

## Crafting

All instruments are crafted at a Workbench.

| Instrument | Recipe |
| --- | --- |
| Lyre | `10 Wood`, `2 Leather scraps` |
| Drum | `8 Wood`, `4 Leather scraps`, `2 Deer hide` |
| Flute | `6 Wood`, `1 Deer hide` |

The instruments are held-only tools. They do not add attacks, buffs, skills,
durability, build pieces, status effects, or Harmony patches.

## Controls

| Control | Action |
| --- | --- |
| `LeftAlt + P` | Toggle play mode while holding a Bardheim instrument |
| `1-8` | Play manual notes or drum hits |
| `9` | Cycle lyre tuning |
| `O` | Play or stop the selected MIDI song |
| `[` / `]` | Select previous or next MIDI song |
| `-` / `=` | Decrease or increase song speed |
| `0` | Reset song speed to `1.00x` |
| `L` | Toggle song looping |
| `Ctrl + F3` | Hide or show the Valheim HUD and Bardheim overlay |

## MIDI Songs

Bardheim loads user MIDI files from:

```text
BepInEx/plugins/Bardheim/songs/
```

Add `.mid` files to that folder, equip the lyre, drum, or flute, toggle play
mode with `LeftAlt + P`, then use `O`, `[`, and `]`. The song list refreshes
when the song controls are pressed, so new files can be added without rebuilding
or reinstalling the mod.

Supported files are Standard MIDI format 0 or 1.

- Lyre playback maps melodic MIDI to the lyre sample bank and mutes channel 10
  percussion by default.
- Drum playback uses General MIDI channel 10 percussion where possible. If a
  song has no mapped percussion, Bardheim falls back to pitch-band mapping so
  melody-only files can still drive the drum.
- Flute playback mutes channel 10 percussion by default, folds melodic notes
  into the `D4-B5` flute bank, and rate-limits dense arrangements so the flute
  remains readable.

Optional sidecar profiles can sit next to a MIDI file:

```text
SongName.mid.lyre-profile.json
SongName.mid.flute-profile.json
```

Profiles can choose active or muted channels, per-channel octave offsets,
arrangement mode, and flute melody density. Profiles are instrument-specific.

## Multiplayer

Multiplayer audio is experimental and disabled by default in `0.7.0`.

If `Multiplayer.EnableMultiplayerAudio` is enabled, every participating player
must have Bardheim installed. Unmodded players are not expected to hear
instrument audio. The current implementation sends transient note-start events
only; it does not synchronize song files, song names, raw audio, save data,
world objects, ZDO state, or server-authoritative music state.

## Configuration

Bardheim uses BepInEx config entries for play-mode toggle, local volume,
overlap limits, MIDI density, visual calibration, and experimental multiplayer
audio. The config file is generated by BepInEx after the plugin runs once.

Most players should leave multiplayer audio disabled for `0.7.0`.

## Current Limitations

- Local play is the accepted release path for `0.7.0`.
- Two-client multiplayer validation is deferred.
- The generated held/world visuals are functional release visuals, not final
  custom Unity asset-bundle art.
- Existing local files from older Lyre Instruments test builds are not migrated
  automatically. Move old song or pose files into the Bardheim folders manually
  if needed.

## Build

The project defaults to the local `valheimbot` r2modman profile:

```powershell
dotnet build src/Bardheim/Bardheim.csproj `
  /p:RestoreSources=https://api.nuget.org/v3/index.json
```

To override local paths, set:

```powershell
$env:VALHEIM_INSTALL = "C:\Program Files (x86)\Steam\steamapps\common\Valheim"
$env:BEPINEX_PROFILE_DIR = "$env:APPDATA\r2modmanPlus-local\Valheim\profiles\valheimbot"
```
