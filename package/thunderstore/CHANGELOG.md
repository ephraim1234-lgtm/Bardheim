# Changelog

## 0.7.0

- Renamed the mod to Bardheim with Bardheim runtime IDs and install folders.
- Added playable lyre, drum, and flute instruments.
- Added local Standard MIDI format 0/1 song playback from
  `BepInEx/plugins/Bardheim/songs/`.
- Added MIDI controls for song selection, speed, looping, and playback.
- Added HUD-toggle handling so `Ctrl + F3` hides the Valheim HUD and the
  Bardheim song overlay together.
- Added generated instrument visuals and inventory icons without Unity asset
  bundles.
- Added experimental both-sides-required multiplayer audio, disabled by
  default pending a later two-client validation release.
