# Bardheim Source Assets

This folder contains original source assets for Bardheim.

## Rules

- Do not copy Valheim proprietary assets into this folder.
- Keep source assets separate from generated runtime outputs.
- Record generation prompts, tool versions, and license/provenance notes.
- Keep runtime integration decisions in issue, release, or changelog notes.

## Style Target

Assets should fit a Norse-inspired Valheim-like direction:

- Rustic hand-crafted object language.
- Low-poly or painterly forms.
- Weathered wood, cord, leather, and carved details.
- Readable silhouettes over high-detail realism.
- No modern hardware, glossy fantasy ornament, or polished metal-heavy look.

## Contents

- `icon/`: inventory icon source and generation notes.
- `model/`: model source and generated exports.
- `audio/`: note sample prep scripts, drum raw-clip slicing tools, generated or
  curated one-shot WAVs, and generation/license notes. Current lyre samples are
  derived from user-supplied source clips outside this repository; current drum
  candidate cuts are derived from project-owner raw clips outside this
  repository.
